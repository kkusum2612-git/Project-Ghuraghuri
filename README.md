# Ghuraghuri

Ghuraghuri is a travel planning and vendor management web application developed for the CSE471 System Analysis and Design course.

## Current Scope

- Registration and Login System
- Admin Role and Access Management
- Trip Dashboard and Management
- Hotel Vendor Listing Management
- Guide Registration and Listing Management
- Public Event Room Creation and Discovery

## Technology

- React
- Vite
- Tailwind CSS
- Express
- Node.js
- MongoDB
- Mongoose

## Local Setup

Install dependencies from the repository root:

```bash
npm install
```
